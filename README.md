PrimeMortgage Portal
Overview

PrimeMortgage Portal is a responsive front-end mortgage management website developed using HTML, CSS, and JavaScript. The project provides users with an intuitive platform to explore mortgage services, apply for loans, calculate EMI, monitor loan progress, and view payment history.

Features
Responsive Home Page
Mortgage Loan Application Form
EMI Calculator
Customer Dashboard
Payment History Tracking
Mortgage Progress Monitoring
Monthly Payment Bar Chart (Chart.js)
Professional UI Design
Mobile-Friendly Layout

JavaScript (ES6)
